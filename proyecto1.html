DESARROLLO WEB

Sitio Web Empresarial

Un proyecto ficticio diseñado para demostrar el desarrollo de una página web empresarial moderna, responsiva y fácil de utilizar.

Sobre el proyecto

Este proyecto consiste en el diseño de un sitio web para una empresa ficticia. La página fue desarrollada utilizando HTML5, CSS3 y Bootstrap.

El objetivo principal fue crear una experiencia visual moderna que pudiera adaptarse a diferentes dispositivos, incluyendo computadoras, tablets y teléfonos móviles.

Se utilizaron componentes de Bootstrap para facilitar la creación de una estructura responsiva y mantener una navegación sencilla.

Tecnologías utilizadas

  • HTML5
  • CSS3
  • Bootstrap
  • Diseño Responsive
